# OpenSphere Vue3

基于 Vue 3 和 OpenLayers 构建的 Web GIS 地图应用，提供图层管理、空间数据导入、地图查询、要素样式配置、实时轨迹展示和 2D/3D 地图浏览等能力。

## 功能特性

- **地图浏览**：支持 2D / 3D 模式切换、地图缩放、平移、定位和底图切换。
- **图层管理**：支持矢量图层、WMS 图层的添加、删除、显隐控制、透明度调整和图层排序。
- **数据导入**：支持 GeoJSON、JSON、CSV、KML、GPX、SHP 和 KMZ 文件导入，并在导入后自动定位至数据范围。
- **要素信息**：点击地图要素查看几何类型、中心坐标和属性信息。
- **样式配置**：支持点、线、面样式调整，包括颜色、大小、边框、填充、透明度和线型等。
- **分类渲染**：按属性字段生成分类样式，并通过图例查看分类颜色和名称。
- **空间绘制与量测**：支持点、线、面、矩形绘制，以及长度和面积测量。
- **空间属性查询**：支持属性条件查询和地图范围框选查询。
- **时间数据处理**：识别日期、ISO 时间和 Unix 时间戳字段，支持时间范围筛选和时间轴控制。
- **实时轨迹**：支持通过 WebSocket 接入实时位置数据，提供断线重连、轨迹线和本地模拟数据。
- **轨迹回放**：按轨迹 ID 和时间字段生成回放轨迹，支持进度拖动、倍速播放和地图跟随。
- **点位可视化**：支持点位热力图和聚合气泡展示。
- **坐标转换**：支持 WGS84、GCJ-02 和 BD-09 坐标系之间的经纬度转换与地图定位。
- **工作区管理**：支持保存、恢复和清空工作区，配置保存在当前浏览器的 `localStorage` 中。

## 环境要求

- Node.js 18 或更高版本
- npm 9 或更高版本

## 快速开始

### 安装依赖

```bash
npm install
```

### 启动开发服务

```bash
npm run dev
```

开发服务默认运行在 `http://localhost:5173`。

### 类型检查

```bash
npm run typecheck
```

### 构建生产版本

```bash
npm run build
```

### 预览生产构建

```bash
npm run preview
```

## 环境变量

复制 `.env.example` 为 `.env.local`，根据需要配置服务密钥：

| 变量 | 必填 | 说明 |
| --- | --- | --- |
| `VITE_TDT_TOKEN` | 否 | 天地图服务密钥。配置后可使用天地图矢量和影像底图。 |
| `VITE_AMAP_WEB_KEY` | 否 | 高德 Web 服务密钥。配置后启用高德地点搜索。 |

未配置天地图密钥时，应用会保留 OpenStreetMap 和 ArcGIS 影像作为开发环境下的底图选项。实际部署时请根据服务商要求配置合法密钥，并确认相关服务允许浏览器跨域访问。

## 使用说明

### 本地空间事件处置演示

工作台的“事件”入口提供一条仅在浏览器本地运行的空间事件处置演示流程：新建或导入事件、在地图上研判、分派、处置更新、主管审核，以及在“事件记录”中复盘。事件导入仅接受 `.csv`、`.geojson` 与 `.json`；它与顶部的通用 GIS 图层导入相互独立。

- 事件、时间线、导入批次、演示成员与分类保存在当前浏览器/域名的 **IndexedDB**；演示角色偏好保存在 `localStorage`。
- 顶栏的“演示角色：管理员 / 调度员 / 主管（本地）”只改变可用操作，用于同一浏览器内的流程演示；本期不提供真实登录、账号、身份服务或多人在线协作。
- 本期不提供跨浏览器同步或服务器端事件服务。清除该站点的浏览器数据会清除本地事件数据，其他浏览器不会收到更新。
- 管理员可在事件工作区使用“重置本地事件演示数据”；操作会重新写入演示种子事件、时间线和导入批次，不会删除普通 GIS 图层或地图工作区。

### 导入空间数据

点击顶部的“导入数据”，选择支持的本地文件。导入完成后，数据会出现在图层列表中，地图会自动缩放到数据范围。CSV 文件需要包含经纬度字段，系统会根据常见字段名称识别坐标信息。

### 添加 WMS 图层

点击“添加 WMS”，填写图层名称、服务地址和服务图层名。WMS 服务需要支持浏览器直接访问；如服务存在跨域、鉴权或内网访问限制，请通过后端代理提供访问地址。

### 接入实时轨迹

在“实时轨迹”面板输入 `ws://` 或 `wss://` 地址后连接，也可以使用“本地模拟”查看示例效果。位置消息至少需要包含目标 ID 和经纬度，支持以下常见字段：

```json
{
  "id": "vehicle-001",
  "lon": 113.6254,
  "lat": 34.7466,
  "timestamp": "2026-07-14T10:30:00Z",
  "name": "巡检车 001"
}
```

目标 ID 支持 `id`、`trackId`、`deviceId` 和 `vehicleId`；经度支持 `lon`、`lng` 和 `longitude`，纬度支持 `lat` 和 `latitude`。服务端可以发送单个对象、对象数组，或使用 `{ "data": ... }` 包装的数据。

### 保存工作区

通过“工作区”菜单可以保存、恢复或清空当前地图状态。工作区包含底图、视图位置、WMS 配置、矢量数据、图层样式、时间设置和查询条件，仅对当前浏览器和域名有效。

## 项目结构

```text
src/
├─ components/       地图面板和业务组件
├─ map/               地图引擎、图层、样式和交互逻辑
├─ search/            地名、坐标和图层搜索服务
├─ stores/            Pinia 状态管理
├─ types/             GIS 与工作区类型定义
├─ views/             页面视图
├─ workers/           空间文件处理 Worker
├─ App.vue            应用根组件
└─ main.ts            应用入口
```

## 注意事项

- 外部底图、WMS、地点搜索和 WebSocket 服务需要满足网络连通、鉴权和 CORS 配置要求。
- 工作区数据保存在浏览器本地，清除站点数据后将无法恢复。
- 实时连接和轨迹回放属于临时地图状态，不会写入工作区快照。
- 3D 模式适合浏览普通矢量图层、实时轨迹和轨迹回放；部分 2D 专属工具需要切换回 2D 模式使用。
